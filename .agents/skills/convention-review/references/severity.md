# Finding severity

| Severity | What it means | Example categories |
| --- | --- | --- |
| **CRITICAL** | Security, privacy or data-loss risk. Blocks merge. | Hardcoded secrets, SQL injection, path traversal, command injection, secrets in logs, `.env` added to the repo. **Project-specific:** an IP address stored, logged or exported in any form; an access log switched on in uvicorn or Caddy; a participant page that loads a script, font, image or beacon from another origin; a session row or any participant data written before consent; "I don't agree" or "Leave study" that leaves data behind; deletion that is a flag instead of a hard delete; an export or admin table that contains anything beyond the fields listed in [`privacy.md`](../../../rules/privacy.md); an `/api/admin` route reachable without the admin dependency; an admin cookie without `Secure`, `HttpOnly` or `SameSite`; admin credentials logged or returned; a storage key built from a user-supplied filename; an upload accepted without decoding it as an image; a way to delete or reorder the consent step. |
| **HIGH** | Study validity, architecture or data integrity. Should fix before merge. | Bare `except` / `except Exception` without re-raise; raw `dict[str, Any]` crossing a layer; mutable default arguments. **Project-specific:** a timed step that can be shown twice to one session, or that renders before the server recorded its start; reaction time measured from anything but the painted frame, or started before the image was preloaded; click coordinates not normalised to the displayed image; assignment that reads counts and inserts outside one immediate transaction; a participant response that reveals other variants, their images or target boxes; a structural edit accepted on a published form, or the rule enforced only in the UI; preview that writes data; a service importing FastAPI or committing the session; blocking I/O inside `async def`; a model change without an Alembic revision, or an edited applied revision; a step type missing one of its five parts (schema, plugin, editor card, CSV columns, tests); CSV columns that change order or name for the same form structure; a hand-built UI primitive in the admin where a shadcn/ui component exists. |
| **MEDIUM** | Quality, observability, testability. Fix during review. | f-string log messages; missing tests for new behaviour; magic numbers; missing docstrings on public functions; user-supplied text in an error message. **Project-specific:** a stimulus image that can overflow the viewport on a phone; a destructive admin action without a confirmation that names what is lost; autosave with no visible state or no failure path; technical wording ("slug", "payload") in admin UI text; decoration or colour in the participant view that competes with the stimulus; a hardcoded limit, timeout or URL that belongs in settings; `pointerType` not recorded with a click. |
| **LOW** | Polish, naming, dead code. Optional. | Vague variable names, TODO without issue reference, commented-out code, inconsistent naming. |
