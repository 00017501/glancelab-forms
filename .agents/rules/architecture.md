# Architecture Conventions

Examples: [architecture examples](../references/architecture-examples.md).

One process, one SQLite file, one admin. Keep the structure as small as the product. Business rules must still be testable without HTTP.

---

## Layers

[Example](../references/architecture-examples.md#layer-diagram). Tree: [source tree](../references/architecture-examples.md#source-tree).

| Layer | Folder | Does | Must not |
|---|---|---|---|
| Transport | `app/routers/` | Parse input, call one service function, return a schema | Hold business rules, build queries |
| Services | `app/services/` | Business rules and queries | Import FastAPI or Starlette, commit |
| Models | `app/models/` | SQLModel tables | Contain behaviour beyond simple properties |
| Schemas | `app/schemas/` | Pydantic request, response and step-config models | Touch the database |
| Storage | `app/storage/` | Object storage client behind a small interface | Know about forms or sessions |

Dependencies point one way: routers → services → models and storage. Nothing imports from `routers/`.

### Rules

- Services are plain functions that take `session: Session` first and typed arguments after. No service classes unless there is shared state to hold.
- There is no repository layer. Services use SQLModel `select(...)` directly. Extract a query helper the second time the same query is needed.
- Services raise exceptions from `app/errors.py`. The central handler in `main.py` turns them into HTTP responses.
- Rules that need no database are pure functions: choosing a variant from counts, the hit test for a target box, flattening results into CSV columns, deciding whether an edit is text-only. Test them with plain values.

---

## Transactions

- The request session dependency commits on clean exit and rolls back on exception. Services never call `commit()` or `rollback()`.
- Call `session.flush()` when an ID is needed mid-request.
- Variant assignment must read counts and insert the session in one `BEGIN IMMEDIATE` transaction, so simultaneous starts cannot pick from the same stale counts.
- SQLite runs in WAL mode with foreign keys on. Both are set when the engine connects.

---

## Sync, not async

SQLite through SQLModel and boto3 are both blocking. Route handlers and services are plain `def`; FastAPI runs them in its thread pool. Never call blocking code from an `async def`.

---

## Step types

[Example](../references/architecture-examples.md#step-config).

A step's settings are a JSON column validated by a Pydantic discriminated union on `type`. Adding or changing a step type touches five places, in one change:

1. The config schema in `app/schemas/steps.py`.
2. The participant plugin in `frontend/participant/`.
3. The editor card in `frontend/admin/`.
4. The CSV columns in the export service.
5. Tests for the schema and the export.

Result payloads are typed the same way. No raw `dict` leaves a service.

---

## Storage

- The database holds image metadata only. Bytes live in object storage.
- The same client serves SeaweedFS and AWS S3; the difference is settings, never code.
- Storage keys are generated by the server and never built from a filename the user supplied.
- Images reach browsers through the backend at `/img/{key}`, not through a storage URL.

---

## Migrations

- Every model change ships with an Alembic revision, autogenerated and then read by hand.
- Never edit a revision that has been applied anywhere.
- Use batch mode: SQLite cannot alter most columns in place.

---

## Choosing a data structure

|Situation|Use|
|---|---|
|Data from a request, the database JSON column or storage|Pydantic model|
|Internal only, never serialized|`dataclass`|
|Fixed set of options|`StrEnum`|
|Temporary, used in one function|`tuple` or `NamedTuple`|

## Where does this logic live?

|Situation|Put it in|
|---|---|
|Request parsing, response shape|Router|
|Rules, decisions, queries|Service|
|Admin login check|Router-level dependency|
|Object storage calls|`app/storage/`|
|Environment values|`app/settings.py`|
|Time, random IDs, small helpers|`app/utils.py`|
